## 4. How to regenerate the figures (from the user's own copies)

1. Foxon 2023 (class A and B): place the PDF at `z32_independent_audit/input/2023-982.pdf`, then run `bash run_all.sh` from `z32_independent_audit/`. Step 0 extracts the page 8 and page 9 figures; `scripts/make_grid_overlay.py` draws the grid.
2. arXiv 2403.17350v1 (classes A, C): `pdfimages -png -f 1 -l 1 PAPER.pdf img/p01`, `-f 31 -l 31 ... img/p31`, `-f 5 -l 5 ... img/p05`, `-f 50 -l 50 ... img/p50`. The pages 1 and 31 extractions are performed by `z32_checkpoint/reproduce_z340_from_pdf.sh`. The pages 5 and 50 commands were run inline in the project and are not in an archived script.
3. Z340 derivatives (classes C): run `z32_checkpoint/reproduce_z340_from_pdf.sh` for the atlas and transposition crops; the blinded review sheets are produced by `z32_checkpoint/phase1_working/blind_review2.py` in that run directory.
4. Images with an inline or unknown generator (`check_first_cells.png`, `trans_bw.png`, `trans_suspect_small.png`, `trans_suspect_montage.png`, class E files) cannot be regenerated exactly from the archive. They are not needed for any result in the dossier.
