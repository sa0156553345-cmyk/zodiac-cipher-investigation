# What any proposed Z32 solution must pass (fixed list)

A proposal is treated as a solution only if it passes every criterion below that applies to its claim.
Passing criteria C1-C4 shows reproducibility, not meaning.

| # | Criterion | Operational test | Status of current candidate (T1, Foxon (12,3)) |
|---|---|---|---|
| C1 | Reproduction of the authors' stated steps | Re-run the stated rules; list every added rule | Partly: Fig.1(C) reproduced only with an unstated empty-cell rule (E2) and an inferred direction (delta=+2) |
| C2 | Literal phrase, no edits | Phrase used exactly as written, under the declared rules | Failed: T1 satisfies 0 of 34 valid orders; 1 of 3 pairs on the paper's order |
| C3 | Repeat-symbol consistency | All 3 pairs of repeated symbols carry the same letter | Failed for T1 on the paper's order (2 of 3 pairs violated) |
| C4 | Transposition justified by the source | Every rule traceable to the paper text, or declared as an added rule with its effect | Failed: the empty-cell rule is not in the paper; alternatives change validity or output |
| C5 | Multiplicity declared | Number of phrases and orders tested, and the family's definition, fixed before the test | Done for the alternative family: N = 3544 phrases, M = 34 orders |
| C6 | Excess over chance after multiplicity correction | Family-wide permutation test p < 0.01 and Bonferroni per-phrase p < 0.01 | Failed: global p = 0.417; best per-phrase Bonferroni p = 1.0 |
| C7 | Plaintext quality without edits | Exact phrase is grammatical and meaningful in the source's language | Not met: the best text needs two letter edits |
| C8 | Geographic consistency | Predicted site lies within the stated uncertainty of the claimed place; scale and orientation measured, not assumed | Not established: predicted (12,3) lies 0.2-2.8 mi from the Highway 24 point depending on the model |
| C9 | Discrimination | 95% uncertainty radius of the predicted site below a stated threshold (proposed here: 0.5 mi) | Not met: radius about 0.8-1.4 mi, and the model spread is larger |
| C10 | Independent external evidence | Archive document, survey, or physical verification that is independent of the cipher analysis | Not available in this package |
| C11 | Consistency with other Zodiac messages | Only if a claim relies on context from Z13, Z340 or letters | Not evaluated |

Note: C8 and C9 thresholds are proposed here for this review; they are not standards from the literature.
